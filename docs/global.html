============================================================================ authMiddleware.js - Middleware de autenticación mediante JWT en AdaptiWeb ============================================================================ ¿Qué hace? 1. Intercepta las peticiones HTTP dirigidas a rutas protegidas de la API. 2. Extrae el token JWT desde la cabecera `Authorization: Bearer `. 3. Verifica la firma digital y vigencia del token utilizando `JWT_SECRET`. 4. Valida que el payload contenga la propiedad `id` para impedir que tokens temporales de recuperación de contraseña sean utilizados como tokens de sesión. 5. Inyecta los datos verificados del usuario (`id`, `email`, `nombre`) en `req.usuario` y cede el control al siguiente controlador mediante `next()`. Dependencias: - jsonwebtoken -> verificación criptográfica y decodificación del token JWT. Variables de entorno (.env): - JWT_SECRET: clave secreta compartida para firmar y validar los tokens de sesión.

============================================================================ cuentaController.js - Controlador de gestión y eliminación de cuenta en AdaptiWeb ============================================================================ ¿Qué hace? 1. Procesa la eliminación definitiva de la cuenta del usuario autenticado (`DELETE /api/cuenta`). 2. Extrae el identificador del usuario directamente del token JWT verificado (`req.usuario.id`), evitando cualquier manipulación desde el cuerpo de la petición. 3. Ejecuta el borrado dentro de una transacción SQL atómica (`beginTransaction` / `commit` / `rollback`) para garantizar integridad referencial: primero elimina los registros en las tablas hijas (Tareas, Marcadores, Pomodoro, Preferencias) y finalmente el registro padre en `Usuarios`. 4. Ignora de forma segura el error MySQL `ER_NO_SUCH_TABLE` (1146) en caso de que alguna tabla dinámica aún no haya sido creada para ese entorno. Dependencias: - ../../db -> piscina de conexiones MySQL (`pool`) para obtener una conexión dedicada. - Middleware de autenticación -> inyecta `req.usuario.id` antes de ejecutar el controlador. Tablas afectadas en la base de datos: - Tareas, Marcadores, Pomodoro, Preferencias (tablas hijas) -> Usuarios (tabla principal).
